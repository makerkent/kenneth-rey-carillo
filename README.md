# Kenneth Rey Carillo — Personal Website

A cinematic, dark, futuristic personal profile website.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — cursor glow, reveal animations, and dynamic year

## Quick start
Open `index.html` in a browser.

## Customize first
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the temporary K portrait in the About section with your own photo later.
3. Add links to your GitHub/social profiles if desired.
4. Edit the Projects and Journey sections as your real projects develop.

## GitHub Pages
Upload these three files to a GitHub repository. In the repository:
Settings → Pages → Deploy from a branch → choose `main` and `/root`.

The site can then be reached at:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
