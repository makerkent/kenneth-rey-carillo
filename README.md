# Maker Kent — The Seeker's Archive / Immersive V2

A cinematic profile website for GitHub Pages.

## Features
- Lightweight Three.js ambient 3D star field
- Responsive iPad/mobile layout
- Editorial typography
- Scroll reveal animation
- Magnetic buttons
- Interactive cursor
- Orbit/radar visual language
- No backend and no build step
- CDN-loaded Three.js, so the repository stays small

## Publish
GitHub Pages can publish static HTML/CSS/JS directly from a repository. Create a repository, upload these files, then go to **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

GitHub's documentation: https://docs.github.com/en/pages/quickstart

## Customize
1. Edit `index.html` for your text.
2. Put your profile photo in `assets/`.
3. Replace the email address.
4. If you later want local Three.js instead of the CDN, download the library into the project and change the import in `js/app.js`.

## Important
Do not publish private information such as your home address, phone number, private email, passwords, API keys, or other secrets. GitHub Pages sites are publicly accessible.
